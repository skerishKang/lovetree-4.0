# 러브트리 — 4.1 개발 기준

좋아하는 순간을 남기고, 그 마음이 이어지는 길을 다시 보고 감상하는 팬 기록 서비스.

## 현재 운영·개발 기준

2026-11-01 Owner 결정으로 **앞으로의 신규 기능과 UI/UX 개선은 4.1에 집중한다.**

- 운영·검수: https://lovetree-4-0.pages.dev/v41/
- 4.0 UI: 기존 루트와 경로를 호환용으로 보존한다. 루트/로그인 복귀 주소의 자동 전환은 이번 문서 변경에 포함하지 않는다.
- 저장소는 기존 skerishKang/lovetree-4.0을 계속 사용한다.
- SRC064 첫 화면·금테·카메라와 리모네 Track32/59/58/56의 디자인을 유지한다.
- 두 UI는 PADIEM 공통 인증·COM2 기록 서버/DB와 도메인 규칙을 재사용한다. 별도 DB로 복사하거나 기존 기록을 초기화하지 않는다.

4.1에는 다섯 보기, 빠른 작성, 책장 관리, 부모 재배선/관련 연결, 읽던 위치·주소 복원, 사진/영상 비공개 첨부, 명시적 공유·회수, 발견·커뮤니티가 구현·운영 반영돼 있다. 기본 비공개이며 링크 공유와 발견 노출은 각각 소유자의 명시적 동의를 요구한다.

**구현/운영 반영과 최종 사용자 검증을 구분한다.** 실제 Google 회원 업로드→재로그인→삭제(#14), 실제 기기·소프트키보드·스크린리더(#44)는 미검증이다. 완료 근거와 잔여의 정본 인덱스는 [#1](https://github.com/skerishKang/lovetree-4.0/issues/1)이다.

## 로컬 실행

Node.js 22.13 이상. Windows PowerShell, macOS, Linux에서 같은 명령을 사용한다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

터미널에 표시된 주소의 **/v41/**로 들어간다(기본 개발 포트 예: http://localhost:5173/v41/). Vite만 띄운 환경은 프런트 미리보기이며 운영 인증/API 연결 완료를 뜻하지 않는다. 실제 같은 원진 사슬 준비와 서버 적용 절차는 docs/HANDOFF.md 및 docs/API-PROXY.md를 따른다. 다른 작업의 서버를 종료하거나 중복 실행하지 않는다.

회원 기록은 서버에 저장한다. 예시와 파일 가져오기는 회원 기록과 분리되며 자동 업로드하지 않는다. JSON에는 개인 메모와 링크가 포함되므로 공개 저장소에 커밋하지 않는다. 첨부 파일은 COM2에 별도 비공개 보관되며 JSON 백업에는 URL만 포함된다. DB 백업과 첨부 파일 백업은 별도로 관리해야 한다.

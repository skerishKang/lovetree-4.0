## 2. 데이터 규칙 (꼬리표 → 점·선)

### 점
- **허브(큰 점)**: 확정 꼬리표 값 중 종류가 **가수·노래·무대**인 것. 같은 값을 가진 순간이 **2개 이상**일 때만 허브가 된다. 1개뿐이면 허브를 만들지 않고 순간의 꼬리표 칩으로만 보인다(희귀 값이 지도를 채우는 일을 막는다).
- **순간(작은 점)**: 모든 순간. 꼬리표가 없어도 점이 된다(아래 '꼬리표 없는 순간').
- **멤버·활동기·감정은 1차 허브가 아니다.** 상세 판 칩과 걸러 보기(후속 PR)로 쓴다. 확장은 `TAG_KINDS`에 한 줄만 더하면 되도록 종류 목록을 코드에서 하드코딩하지 않는다.

### 묶음 소속 (순간 하나는 하나의 묶음에만 살고, 선은 여러 허브로)
1. 1차 소속은 **무대 > 노래 > 가수** 순으로 첫 꼬리표를 고른다. 이유: 팬의 기억 단위는 '그 무대에서 본 것'(언제·어디서)이고, 무대가 없으면 노래(무엇), 그것도 없으면 가수(누구)가 남는다.
2. 소속 선은 **1차 허브 → 순간 점**의 짧은 실만 그린다. 1차가 아닌 꼬리표는 상세 판의 칩으로 확인한다(모든 허브에 선을 그리면 가수 하나가 순간 대부분을 잡아 선이 바닥을 채운다).
3. 다만 1차 소속이 하나도 없는 허브(예: 가수:RESCENE — 다른 가수 직캠 2개에만 붙음)는 그 허브나 관련 순간을 골랐을 때만 **점선**으로 연결한다. 기본에는 고아 허브에서 다른 묶음으로 긴 선을 뿌리지 않는다. 발자취 줄과 색·굵기가 달라 섞여 보이지 않게 한다.

### 선
- **발자취 줄(핵심)**: 전체 순간을 **시간 순서**(무대 날짜, #627 0단계; 같은 날은 만든 순서)로 잇지만 **기본에는 그리지 않는다**. 기본 화면에는 묶음 안의 짧은 이음만 아주 옅게 둔다. 순간·허브 선택과 '발자취 걷기'에서만 해당 길을 밝힌다.
- **직접 이은 줄(next/branch)**: 1차 화면에서는 숨기고 상세 판의 '이전·다음 순간'으로 보여 준다. 지도의 parent 선 개념과 섞이면 재료가 지워지기 때문이다. 후속 PR에서 토글을 검토한다.
- **발자취 재생**: 시간 순서대로 현재 점을 밝히고 현재까지 지나온 길만 순서대로 나타낸다. 남은 묶음은 옅게 두어 전체 길을 한꺼번에 얹었을 때 생기는 실뭉치를 막는다. 실제 기록에서도 같은 시간 순서 규칙을 쓴다.

### 꼬리표 없는 순간
- 허브 묶음에 넣지 않고 무대 한쪽의 **'꼬리표 없는' 선반**에 시간 순서로 흐리게 놓는다. 발자취 줄은 이 점도 지난다.
- 선반 안내에 '꼬리표 한 번에 제안받기' 버튼 자리를 둔다 — #680에서 만든 기능(꼬리표 정리 화면)과 연결. 0개면 선반 자체가 없다.
- 지도가 '꼬리표를 채우라는 부드러운 부탁'을 하게 하는 장치다. 숨기지 않고(상태를 숨기지 않는다) 구분해서 보여 준다.

### 순간 1개 · 10개 · 100개
| 순간 수 | 허브 | 무대 모양 |
| --- | --- | --- |
| 1개 | 없음 | 점 하나가 무대 중앙. 안내 문구 "순간이 하나예요. 다음 순간을 남기면 흐름이 보여요." 발자취 줄 없음 |

**안2를 선택한다.** 허브 안의 작은 나선 대신 큰 허브의 바깥 고리에 순간을 놓아 묶음이 한눈에 보인다. 허브 이름은 점·다른 이름·화면 끝에 닿지 않는 묶음 밖 후보 자리를 순서대로 검사한다. 긴 이름은 줄이고, 놓을 자리가 없으면 숨긴다. 줄인 이름의 원본은 SVG title과 범례에서 확인한다.

발자취는 이 배치 위에 얹는 표현이지만 기본에는 숨긴다. 선택한 길 또는 현재까지 걸은 길만 나타나므로 어느 배치에서도 그물 모양 선 덩어리로 화면을 덮지 않는다.

## 4. 화면 구성 (390 · 1440)

공통: 검은 묶음 위 금테 카드 프레임(shell.css의 iframe 프레임과 같은 시각 언어). 색·모서리는 'identity.css'의 '--lt-*' 토큰만 쓴다. 묶음 색은 묶음='--lt-gold-deep', 노래='--lt-rose', 가수='--lt-blue'로 범례와 맞춘다.

- **1440**: 왼쪽 그래프 묶음, 오른쪽 레일(약 340px) = 범례 + 선택한 순간/허브 상세 + 발자취 재생 단추. 위쪽에 '발자취 지도 / 그래프 보기' 전환 알약(설계상 같은 입구, 이번 독립 시안은 메뉴에 연결하지 않음).
- **390**: 그래프가 가용 폭 전체를 쓰고 높이는 58dvh(450~560px 한도). 범례·상세·걷기 단추는 아래로 이어 둔다. 이번 독립 시안은 전체 문서를 캡처할 수 있게 아래 차례로 펼치며, 위 머리 버튼과 범례 항목은 가용 폭 안에서 줄바꿈한다.
- **선택 상세**: 순간은 제목·무대 날짜·감정·꼬리표 칩·메모·발자취 이전/다음. 허브는 **그 노래·묶음의 내 순간 목록**을 바로 연다. 목록에서 순간을 누르면 다시 순간 상세로 이동한다.

## 5. 지금 지도(views/network)와의 관계 — 대체가 아니라 '보기 방식 하나로 추가'

- 지도 입구(트리 ▾ 지도) 안에 **'발자취 지도 / 그래프 보기' 전환 알약**을 둔다. 지금 지도는 parent 선(직접 이은 줄) 중심, 그래프 보기는 꼬리표 중심 — 재료가 다른 두 보기다. 서로를 지우지 않고 한 화면 안에서 고르게 한다.
- 지금 지도 파일(`views/network/**`)은 건드리지 않는다. 그래프 보기는 새 `views/graph/`(예: track HTML + graph-model.mjs + graph.js + graph.css)로 만들고 지도와 같은 runtime 데이터 읽는 방식(`parent.LT41.tree` → 순간 배열)을 따른다.
- 지도의 발자취 수리(첫 순간 경로 강조·예시 전용 재생)는 별도로 하지 않는다(대표 결정). 그래프 보기가 시간 순서 발자취·재생을 실제 기록까지로 넓혀 이 역할을 이어받는다.

## 6. 성능과 표시 한계

- 실제 화면으로 이식할 때는 현재 지도와 같은 **canvas 2D**를 검토한다. 이번 독립 시안은 글자 상자를 실제 렌더에서 측정하기 위해 SVG를 쓰며, 화면·메뉴와 연결하지 않는다. 다른 레인의 'public/v41/graph-model.mjs'를 기다리거나 바꾸지 않는다.
- 허브 이름은 크기 상위 12개로 제한한다. 묶음 원과 점 바깥 후보 네 자리에서 충돌·잘림·점 접촉을 검사하고, 긴 이름은 말줄임하거나 숨긴다. 순간 점 이름은 항상 숨기고 선택 상세로 보여 준다.
- **300순간을 넘기면 묶음을 접는다**: 허브 점 + 'n개' 숫자만 남기고 순간 점은 눌러 펼친다. 펼친 묶음은 한 번에 최대 2~3개로 제한한다.
- 걷기는 루프 하나만 돌고, 매 단계마다 현재 순간과 지나온 길만 다시 그린다. 점을 무작정 크게 늘리거나 실행 때마다 다른 시뮬레이션으로 옮기지 않는다.

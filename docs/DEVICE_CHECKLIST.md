# 러브트리 4.1 실기기 체크리스트 (#44)

대표가 휴대폰으로 **10~15분 안에** 4.1의 핵심 흐름을 확인하기 위한 목록입니다. iOS(Safari·Chrome)와 Android(Chrome) 공통이며, 소프트키보드와 스크린리더(VoiceOver·TalkBack) 항목을 포함합니다. PC·390px 에뮬레이션 결과는 이 검증을 대신하지 않습니다(#44).

- 주소: `https://lovetree-4-0.pages.dev/v41/` (개발 기간 확인 주소)
- 계정: 대표가 쓰는 시험용 계정. 개인정보가 없는 **테스트 사진 1장**만 사용합니다.
- 끝나면 이번에 만든 **시험 트리와 보관 파일을 삭제**합니다. (아래 8번)
- 각 항목은 실제로 해 본 뒤에만 체크합니다. 안 되면 억지로 체크하지 말고 아래 “이상하면 적을 칸”에 적어 주세요.

## 준비 (1분)

- [ ] Wi-Fi 또는 모바일 데이터가 연결되어 있다.
- [ ] 위 주소를 열어 첫 화면이 **5초 안에** 보인다.
- [ ] 오른쪽 위 `로그인`을 눌러 로그인하고, 첫 화면으로 돌아온다.
- [ ] 오른쪽 위에 계정 동그라미가 보인다. (계정 메뉴를 열면 로그인 상태를 알 수 있다)
- [ ] 밤/정원 전환을 한 번씩 해 본다. (계정 메뉴의 `정원`/`밤` 항목)

## 1. 첫 기록 (3분)

- [ ] `새 트리 만들기`를 눌러 첫 여정이 열린다.
- [ ] 00 트리 이름 → 01 첫 장면(링크) → 02 마음/날짜 → 03 다음 → 04 마무리 순서로 진행된다.
- [ ] 각 단계에서 **다음 버튼이 화면 안에 보이고**, 누르면 다음 단계로 간다.
- [ ] 단계 표시(00~04)에서 지금 단계가 읽힌다.
- [ ] 첫 장면 저장 뒤 기억책이 열리고, 방금 쓴 순간이 보인다.
- [ ] `순간 남기기`로 글 순간 1개를 더 남긴다. 저장 뒤 목록/책에 반영된다.
- [ ] `순간 남기기`에서 **테스트 사진**을 첨부해 사진 순간 1개를 남긴다. 저장된다.
- [ ] 기억책에서 사진이 있는 순간을 열면 “사진 불러오기”로 확인할 수 있다. (비공개 사진은 자동으로 펼쳐지지 않는다)

## 2. 보기 전환 (2분)

- [ ] `기억책`·`기억 보드`·`관계 지도`를 차례로 열어 본다. 각 화면이 3초 안에 뜬다.
- [ ] 기억책에서 `목차`(기억 목록)를 열고 닫는다. 목차에 순간들이 보이고, 누르면 그 순간으로 간다.
- [ ] 기억책의 `←`·`→`로 페이지를 넘긴다. 마지막/처음에서 버튼이 비활성으로 바뀐다.
- [ ] 기억 보드에서 순간 카드를 눌러 상세를 열고 닫는다.
- [ ] 관계 지도에서 글자가 겹치지 않고, 순간을 눌렀을 때 상세가 열린다.
- [ ] 어느 화면에서도 **가로 스크롤이 생기지 않는다**. (390폭 기준)
- [ ] 화면 아래쪽 내용이 잘려 올라가지 못하는 곳이 없다.

## 3. 책장·이어 읽기·책 정보 (3분)

- [ ] `내 책장`을 연다.
- [ ] 책이 3권 이상이면 책등 목차가 보이고, 책등을 누르면 아래 책이 그 책으로 움직인다. (1~2권이면 목차가 숨겨지는 것이 정상)
- [ ] `이어 읽기` 칸이 보이고, 누르면 지난번에 보던 책/순간으로 열린다.
- [ ] 책장에서 책을 골라 `기억책 열기`로 들어간다.
- [ ] 상단 `책 관리`(책 정보 관리)를 연다.
  - [ ] 디자인 표지를 하나 고르고 `책 정보 저장`을 누른다. 책장 표지에 그 디자인이 보인다.
  - [ ] 같은 창에서 **새 사진**을 골라 표지로 만든다. 사진 표지가 책장에 보인다. (사진은 새 순간으로도 남는다)
  - [ ] 다른 책의 `책 관리`를 열었을 때, 디자인 표지 선택이 **그 책의 저장값**과 같은가? 이전 책에서 고른 디자인이 그대로 남아 있으면 이상입니다.
- [ ] 책장으로 돌아와 표지가 잘리지 않고 이름·순간 수·마지막 날짜가 읽힌다.

## 5. 공유 (2분)

- [ ] 기억책에서 `공유`를 열고, 처음 순간·보기(기억책)를 확인한 뒤 `미리보기` → `새 공유 주소 만들기`를 누른다.
- [ ] 공유 주소가 만들어지고 복사된다.
- [ ] 브라우저의 **시크릿/프라이빗 탭**(로그아웃 상태)에서 그 주소를 연다.
- [ ] 공유 화면이 열리고, 공유한 순간을 읽을 수 있다.
- [ ] **비공개 사진은 공유 화면에서 보이지 않는 것이 정상**이다. 깨진 이미지·빈 박스·깨진 아이콘이 보이면 이상이다.
- [ ] 공유 화면에 `제목 고치기`·`다음 순간 남기기` 같은 **수정 버튼이 보이면 이상**이다. (감상 전용이어야 한다)
- [ ] 공유 화면에서 로그인 화면으로 갑자기 이동하지 않는다.
- [ ] **(11-11 추가)** Android Chrome: 휴대전화 주소를 **YouTube 앱 등 다른 앱에서 공유 → 러브트리**로도 담아 본다 — 앱이 주소를 `text`(예: `제목 https://youtu.be/…`)나 제목에 담아 보내도 주소만 담긴다. (설치 전에는 공유 시트에 없는 것이 정상)
- [ ] **(11-10 추가)** 같은 주소를 두 번 공유하거나 담기 뒤 새로고침해도 **한 번만 담기는지** 본다.
- [ ] **(11-10 추가)** iPhone 등 Web Share Target 미지원 브라우저에서는 공유 시트에 뜨지 않는 것이 정상 — 대신 `순간 남기기 → 빠른 추가` 주소 칸 **붙여넣기**로 같은 흐름을 확인한다.
- [ ] **(11-10 추가)** PC·휴대전화 공통: 주소 입력 칸 **밖**에서 Ctrl/Cmd+V(또는 붙여넣기 메뉴)로 담기고, **입력 칸 안**에서는 평소대로 칸에 붙는다.

## 6. 소프트키보드 (2분)

- [ ] `순간 남기기`를 열고 마음 한마디 입력칸을 누른다. 키보드가 열린다.
- [ ] 키보드가 열린 채로 제목·감정·날짜 칸으로 이동할 수 있다.
- [ ] 키보드가 열린 채로 `저장`·`취소` 버튼이 보이거나, 스크롤해서 닿을 수 있다.
- [ ] 빈 제목/오류를 만들었을 때 오류 문구가 키보드에 가리지 않는다.
- [ ] 키보드의 `완료`/`다음`(iOS) 또는 뒤로 가기(Android)로 키보드를 닫을 수 있다.
- [ ] 첫 여정의 트리 이름·메모, 책 정보의 제목·표지 사진 제목에서도 같은지 확인한다.
- [ ] 키보드를 닫은 뒤 화면이 원래 위치로 돌아오고, 입력한 값이 남아 있다.

## 7. 스크린리더 (2분)

> iOS: 설정 → 손쉬운 사용 → VoiceOver. Android: 설정 → 손쉬운 사용 → TalkBack.

- [ ] 첫 화면 위 메뉴 이름과 순서가 읽힌다. (첫 화면·내 책장·둘러보기·기억책·기억 보드·관계 지도)
- [ ] 오른쪽 위 계정 동그라미의 이름이 자연스럽게 읽힌다. (예: “내 계정 메뉴, …으로 로그인됨”)
- [ ] 첫 여정에서 지금 단계와 필수 입력을 알려 준다.
- [ ] 기억책에서 페이지 위치(예: “01 / 02”)와 목차 열기/닫기가 읽힌다.
- [ ] 책장의 `이어 읽기` 칸과 책등 목차가 이름과 함께 읽힌다.
- [ ] 책 정보 관리에서 디자인 표지 라디오가 이름·선택 상태와 함께 읽힌다.
- [ ] 대화상자를 닫으면 초점이 원래 버튼으로 돌아온다.
- [ ] 오류·저장 완료 안내가 소리로 읽힌다.

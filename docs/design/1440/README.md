# 순간 정리 새 방식 화면안 (#1440)

## 범위와 열어 보는 법

대표가 고를 수 있도록 만든 독립 시안이다. 제품 화면에 연결하지 않고, 실제 계정이나 저장 요청 없이 가짜 순간과 트리만 사용한다. 기준 main: `3f0d2d0`. #1439의 정리 기능은 이미 병합되었고, #1375의 보기와 색 테마 분리 원칙을 따른다. #1501의 설계 우선 초안 형식을 참고했다.

저장소 루트에서 정적 서버를 열고 `docs/design/1440/index.html?view=cards&theme=night`로 들어간다. 정원은 `theme=garden`으로 바꾼다. 서버는 저장소의 `public/fonts`를 `/fonts/`로 제공해야 제품과 같은 글꼴을 볼 수 있다. 위쪽 시험 상태 선택으로 보통·트리 하나·순간 없음의 차이를 볼 수 있다. 쿼리 없이 열면 기기에 기억한 방식 또는 지금 방식이 기본이다. 화면안의 지금 방식은 비교용 모사이며 기존 제품을 대신하지 않는다.

## 1. 화면 흐름

### 넓은 화면

- 현재 창의 제목, 설명, 표지, 체크칸, 둥근 단추를 유지한다. 왼쪽에 순간 목록, 오른쪽에 대상 트리 카드(맨 앞 + 새 트리)를 두고 각 목록만 스크롤한다.
- 체크칸으로 여러 순간을 고른다. 끌기 시작한 순간이 고른 목록에 없으면 그 순간 하나를 고른다. 끌고 있는 동안 고른 수를 알리고 놓을 카드에 금색 테두리와 밝은 바탕을 함께 표시한다.
- 일반 끌기는 옮기기만 한다. 놓기, 카드 누르기, 키보드로 카드 실행은 같은 이동 요청을 만든다. 고르지 않은 상태는 대상 비활성화. 놓을 수 없는 곳이나 취소는 기록을 바꾸지 않는다.
- 복사하기 단추를 누르면 대상 카드에 체크칸이 나타난다. 여러 대상을 고른 후 확정 단추를 눌러 한 번에 복사한다. 옮기기로 돌아가면 대상 선택만 풀고 순간 선택은 유지한다.
- 이미 있는 순간이 포함되면 카드에 이미 있음(일부면 개수) 표시. 기존 확인 창에서 그래도 넣기·건너뛰기·취소를 선택한다. 여러 대상이면 각각 확인하고 마지막에 한 번만 적용한다.

### 휴대폰

- 순간 목록은 기존과 같은 세로 스크롤. 끌기 손잡이 및 끌기 동작 없음. 바닥 고정 줄에 고른 수·옮기기·복사하기를 두고 내용이 그 줄 뒤에 가려지지 않게 한다.
- 옮기기 또는 복사하기 → 트리 목록 전체 화면. 순간 목록은 숨기고 초점도 이동한다. 위쪽은 뒤로 가기·질문·겹친 순간 썸네일. 대상 카드는 한 줄에 하나씩, 새 트리가 맨 앞이다.
- 옮기기는 카드 한 번 누르기. 복사는 여러 트리 체크 뒤 바닥 확정 단추. 중복 확인 창은 그 위에만 열리고 취소하면 선택 유지.
- 뒤로 가기·휴대폰 뒤로 가기·키보드 취소는 대상 페이지에서 순간 목록으로만 돌아간다. 고른 순간과 스크롤 위치 및 해당 단추 초점을 복원한다. 대상 선택은 초기화한다.
- 작업 완료 후 순간 목록으로 돌아오고 이번 작업을 통째로 되돌릴 수 있는 알림을 띄운다. 시안은 비교하기 쉽게 알림을 자동으로 거두지 않으며, 제품은 기존 공용 타이머를 사용한다.

### 빈 상태와 새 트리

- 다른 트리가 없을 때 + 새 트리 카드와 안내만 남긴다. 순간 0개면 빈 안내를 표시하고 실행 단추는 사용할 수 없게 한다.
- 새 트리는 작은 이름 입력 창을 열고 확정 후 현재 선택한 순간을 담는 안을 시연한다. 새 트리에서 복사와 되돌리기까지 한 작업으로 묶는 부분은 아래 선택과 구현 검토가 필요하다.

| 새 부품 제안 | 대상 트리 카드, 놓기 표시, 고른 순간 미리보기, 대상 페이지 | 그리기와 초점·끌기·뒤로 가기만 맡기고 저장하지 않음 |

제품 구현에서는 정리 명령을 한 곳에 둔다. 보기가 직접 기록을 쓰지 않도록 `cleanup.mjs`의 선택 읽기와 작업 실행을 분리해 같은 함수에 선택한 순간·대상·이동 또는 복사 모드를 전달한다. 기존 `organizeMoments`, `undoOrganize`, `duplicatesByTree`를 유지한다. 현재 완료 함수는 창을 닫으므로 새 방식에서만 목록으로 돌아오는 표시 흐름이 필요하다. 새 트리로 담는 기존 `treeFromMoments`는 일반 정리와 완료 방식이 다르므로 복사 및 한 번 되돌리기를 포함하는 작업 기록을 따로 검토한다. 중복 판정은 같은 영상과 시작 초, 같은 파일, 같은 원본에서 온 사본이라는 기존 약속을 바꾸지 않는다.

설정에는 '순간 정리 방식'을 추가한다. 기본값은 지금 방식, 잘못된 값도 지금 방식으로 돌아간다. `localStorage`는 읽기·쓰기 각각 실패해도 화면을 사용할 수 있게 한다. 새 보기 모듈의 수명 종료 시 끌기·이벤트·관찰자·타이머·임시 뒤로 가기 상태를 정리한다.

## 3. 복사 방식 제안

**단추 방식 권장.** 복사는 여러 트리를 한 번에 고르는 기능이 있으므로, 보조 키만으로 복사하면 한 대상씩 끌어야 하고 이동과 복사를 구별하기 어렵다. 명시적인 모드는 키보드·휴대폰에서도 같은 말로 이해된다. 보조 키 방식은 나중에 빠른 조작을 원하는 사용자에게 추가할 수 있지만 끌기 중 키가 바뀌면 작업 종류를 반드시 알려야 한다. 시안은 일반 끌기 이동과 명시적 복사만 구현한다.

## 4. 키보드와 화면 읽기

- 기본 체크칸과 단추를 쓴다. 탭으로 순간 체크칸 → 이동·복사 또는 대상 카드 이동. 스페이스로 체크, 엔터로 카드 실행. 복사 대상 체크칸도 스페이스로 고른다.
- 초점 표시를 색상 변화만으로 대신하지 않는다. 화면 읽기에는 순간 제목, 트리 이름, 순간 수, 이미 있음 및 고른 상태를 함께 전달한다. 장식용 썸네일은 중복으로 읽지 않게 한다.
- 선택 개수와 완료 알림은 정중한 실시간 영역, 대상 화면 진입 시 질문에 초점, 복귀 시 입구 단추로 초점 복원. 중복·새 트리 창은 기본 대화 상자 초점 가두기와 취소 사용.
- 제품 구현 시 44픽셀 누름 영역, 화면 읽기 실기기 시험, 브라우저 뒤로 가기와 기존 닫기 확인의 우선순위를 확인한다. 끌기는 보조 수단이고 키보드만으로 모든 작업을 완료할 수 있어야 한다.

## 6. 대표가 골라야 할 것

권장안을 먼저 적었다. #1440에서 이미 정해진 지금 방식 기본값, 휴대폰 전체 대상 페이지, 복사 여러 대상, 중복 허용, 되돌리기는 다시 결정할 사항이 아니다.

| 선택할 것 | 선택지 |
|---|---|
| 복사 조작 | 가. 명시적인 복사 단추만 (시안) / 나. 단추와 보조 키 함께 / 다. 보조 키로 끌기 중심 |
| 트리 카드 모양 | 가. 표지·이름·순간 수 (시안) / 나. 작은 표지·이름 / 다. 이름·순간 수만 |
| 새 트리 만들기 | 가. 이름 입력 후 즉시 담기 (시안) / 나. 이름과 표지 함께 / 다. 기존 트리 만들기 화면을 거쳐 담기 |
| 새 트리와 복사 | 가. 복사 모드에서도 새 트리를 만들고 복사 (시안) / 나. 새 트리는 이동만, 복사는 기존 트리만 |
| 넓은 화면 배치 | 가. 왼쪽 목록·오른쪽 두 열 카드 (시안) / 나. 오른쪽 한 열의 넓은 카드 |
| 넓은 화면 완료 후 | 가. 순간 목록으로 복귀 (시안) / 나. 기존처럼 창 닫고 알림 |
| 좁은 화면 기준 | 가. 700픽셀 이하 (시안) / 나. 기존 카드 창 기준 520픽셀 이하 / 다. 화면 폭과 터치 입력을 함께 판단 |

결정 이후 제품 구현은 별도 변경으로 진행한다.

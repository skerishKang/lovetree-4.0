# LoveTree 4.0 제품 방향

2026-10-27 Owner 대화 기준. 기술·시각 구현은 수정 가능하다.

## 중심

좋아하는 대상과의 순간을 남기고, 그 마음이 어떻게 이어졌는지 다시 보고 감상하는 팬 기록 서비스.

팬의 생각과 해석은 감정 기록 안에 포함한다. 공부·업무·범용 아이디어를 다루는 생각트리는 별도 서비스로 둔다. 기존 서비스는 출시하지 않았으며 DB 회원·데이터는 Owner가 만든 테스트 자료다. 새 DB로 시작할 수 있고 과거 데이터 이전은 필수 선행 작업이 아니다. 이전 DB를 삭제할 필요도 없다.

## 핵심 경험

1. 첫 화면의 예시 순간을 눌러 감정과 연결을 이해한다.
2. 좋아하는 대상과 지금 남기고 싶은 순간을 적는다. 최초 입덕일을 요구하지 않는다.
3. 제목·마음 한마디·감정을 담고 첫 순간을 저장한다.
4. 다음 순간을 추가하며 어디에서 이어졌는지와 선택적인 연결 이유를 남긴다.
5. 나중에 다시 열어 그때의 마음을 감상한다.

첫 성공은 화면 수가 아니라 **사용자가 첫 순간과 다음 순간을 연결하고, 저장 후 다시 열 수 있는 것**이다.

## 현재 화면 구조

- 시작/예시: 제품의 감정을 전달하고 첫 행동으로 초대한다.
- 내 트리/책장: 트리 한 개를 책 한 권으로 표현하는 보조 목록이다. 기억책으로 읽거나 트리 연결 보기로 이동하고 백업한다. 책 제작 서비스로 제품 방향을 바꾼 것은 아니다.
- 트리 작업/감상: 같은 순간 데이터로 연결 보기와 시간순 보기를 제공한다.
- 기록 폼: 별도 온보딩 페이지 대신 모달로 연결한다.

## 판단 대기 사항

- 첫 화면은 SRC064 부유 카드로 선택했다. 59번 기억책을 감상 보기로 연결했으며, 58번 기록 보드와 56번 관계망은 후속 검토·구현 대상이다.
- 초기 공개 기본값, 공개 탐색 노출 조건, 유료화는 아직 확정하지 않았다. 과거의 공개 기본/비공개 유료 정책을 자동 승계하지 않는다.
- 서버 단계에서 로그인 방식, D1 스키마, 소유권과 공개/비공개 조회 계약을 함께 정한다.
- 기존 원본 전체 수집을 제품 구현의 선행 게이트로 두지 않는다.

## 구현 순서

1. 현재: 로컬에서 동작하는 기록·연결·재방문 경험과 두 PC 협업 기반.
2. 대표 사용 흐름 확인 후 첫 UI 조정.
3. 계정/인증 + Worker/D1 저장. 인증 없이 공개 쓰기 API를 배포하지 않는다.
4. 소유권·공개 범위가 동작한 뒤 공유 링크와 공개 감상.
5. 필요하면 이미지 업로드/R2, 이후 사용 근거에 따라 추가 기능.

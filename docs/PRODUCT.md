# LoveTree 4.0 제품 방향

2026-10-27 Owner 대화 기준. 기술·시각 구현은 수정 가능하다.

## 중심

좋아하는 대상과의 순간을 남기고, 그 마음이 어떻게 이어졌는지 다시 보고 감상하는 팬 기록 서비스.

팬의 생각과 해석은 감정 기록 안에 포함한다. 공부·업무·범용 아이디어를 다루는 생각트리는 별도 서비스로 둔다. 기존 서비스는 출시하지 않았으며 DB 회원·데이터는 Owner가 만든 테스트 자료다. 새 DB로 시작할 수 있고 과거 데이터 이전은 필수 선행 작업이 아니다. 이전 DB를 삭제할 필요도 없다.

## 핵심 경험

1. 첫 화면의 예시 순간을 눌러 감정과 연결을 이해한다.
2. 좋아하는 대상과 지금 남기고 싶은 순간을 적는다. 최초 입덕일을 요구하지 않는다.
3. 제목·마음 한마디·감정을 담고 첫 순간을 저장한다.
4. 다음 순간을 추가하며 어디에서 이어졌는지와 선택적인 연결 이유를 남긴다.
5. 나중에 다시 열어 그때의 마음을 감상한다.

첫 성공은 화면 수가 아니라 **사용자가 첫 순간과 다음 순간을 연결하고, 저장 후 다시 열 수 있는 것**이다.

## 현재 화면 구조

- 시작/예시: 제품의 감정을 전달하고 첫 행동으로 초대한다.
- 내 트리/책장: 트리 한 개를 책 한 권으로 표현하는 보조 목록이다. 기억책으로 읽거나 트리 연결 보기로 이동하고 백업한다. 책 제작 서비스로 제품 방향을 바꾼 것은 아니다.
- 트리 작업/감상: 같은 순간 데이터로 연결(트리)·시간·보드·줄기 네 보기를 제공하고 보기 사이 선택이 유지된다.
- 기록 폼: 별도 온보딩 페이지 대신 모달로 연결한다.

## 타이포그래피 결정 — 2026-10-28(적용 완료: PR #58, 2026-10-28 main 병합)

선택 확정·main 적용 완료. 결정 문서는 PR #56, 구현은 PR #58이다. 구현 이슈: [#55](https://github.com/skerishKang/lovetree-4.0/issues/55). 적용 근거: `src/styles.css`의 `@font-face`(MaruBuri)·`--ui`(Pretendard Variable) 선언과 `public/fonts/`(출처·SHA-256·라이선스 전문 동봉). 실제 렌더 확인 기록은 `docs/HANDOFF.md`의 #55 항목이다. 아래 문단은 결정 시점 기록을 보존한 것이다.

- **Pretendard**: 첫 화면·내 트리·트리·메뉴·작성/수정 팝업·본문·입력・버튼의 공통 UI 글꼴. 한글·영문·숫자를 같은 기본 가족으로 맞춘다.
- **MaruBuri**: 기억책의 감상 제목에만 사용한다. 작성창 제목이나 조작 메뉴에 명조를 확장하지 않는다.
- SRC064의 사진·카드 구성·분위기는 유지한다. reference 원본과 이미지 내부 글자는 수정하지 않는다.
- 공식 배포본의 고정 버전으로 자체 호스팅하고 저작권 안내·라이선스 전문을 동봉한다. Pretendard는 SIL OFL 1.1, MaruBuri는 네이버 공식 배포 조건을 따른다.
- 자체 호스팅도 실패 가능성이 있으므로 시스템 대체 글꼴·font-display와 로딩 실패 상태를 검증한다.
- 본문·입력 16px, 설명 14~16px, 버튼 14~16px/500~600을 비교 출발값으로 삼는다. 최종 크기·행간·자간은 PC/390px 실제 화면에서 조정하며 날짜·숫자를 일괄 굵게 만들지 않는다.
- Shadow DOM 화면까지 실제 렌더 글꼴, 긴 한글 제목·날짜·placeholder·넘침·버튼 잘림을 확인한다. 저장·인증·탐색 기능은 변경하지 않는다.

조사 기준(적용 전 기록 보존): PR #54 `a69e1df`의 `src/styles.css`는 DM Sans/Noto Sans KR 및 Gowun Batang을 선언한다. `app/styles/v4/`·Gowun Dodum/Manrope를 현재 4.0 기준이라고 한 조사 결과는 채택하지 않았다.

공식 출처: [Pretendard](https://github.com/orioncactus/pretendard), [네이버 글꼴·라이선스 안내](https://hangeul.naver.com/font). 결정 문서 PR은 문서만 변경했고, 실제 교체는 PR #58로 완료됐다(운영 Pages 배포도 같은 빌드를 쓴다).

## 판단 대기 사항

- 첫 화면은 SRC064 부유 카드로 선택했고, 59번 기억책·32번 책장에 더해 58번에 대응하는 보드 보기와 56번에 대응하는 줄기 보기까지 구현돼 있다(2026-10-29 기준). 남은 검토: 55의 부모 재배선(한 순간에 부모 여럿)은 트리 경로·읽기 순서를 바꾸는 결정이라 별도 합의가 필요하다.
- 초기 공개 기본값, 공개 탐색 노출 조건, 유료화는 아직 확정하지 않았다. 과거의 공개 기본/비공개 유료 정책을 자동 승계하지 않는다.
- 저장·인증 채택 구조(2026-10-29): PADIEM 공통 인증 + COM2 기록 서버(PostgreSQL) + Pages 프록시다. 구현은 main에 있다(`src/sync.js`, `server/`, `functions/`; PR #59·#64·#69·#75). Cloudflare Worker/D1을 4.0의 확정 저장 구조로 읽지 않는다. 남은 것: COM2 운영 설치 마무리와 실제 계정 E2E는 #13·#57 기록과 `docs/HANDOFF.md` `운영 연결 진행`을 따르고, 공개/비공개 조회 계약은 #15에서 정한다.
- 기존 원본 전체 수집을 제품 구현의 선행 게이트로 두지 않는다.

## 구현 순서

2026-10-27에 적은 순서이며, 2026-10-29 기준 진행 상태를 덧붙인다.

1. 완료: 로컬에서 동작하는 기록·연결·재방문 경험과 두 PC 협업 기반.
2. 완료: 배포본 실사용 검토(#38) 이후 UI 개선 다수(#39~#47, #55, #81, #84~#87).
3. 구현(main): 계정/인증 + 서버 저장 — PADIEM 공통 인증 + COM2 기록 서버 + Pages 프록시. 인증 없이 공개 쓰기 API를 배포하지 않는다. 운영 설치·실제 계정 E2E 잔여는 `docs/HANDOFF.md`와 #13·#57 기록을 따른다.

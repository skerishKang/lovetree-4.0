## 우선 수정 순서

1. 데이터와 다른 관계 지도 빈 그룹을 제거한다. 원본 디자인을 바꾸지 않고 실제 그룹 수·범위를 맞춘다.
2. 모바일 보드의 첫 진입 확대율과 선택 카드/상세 진입을 정리한다.
3. 모바일 관계 지도에 선택 순간명·상세로 가는 행동을 명확히 표시한다.
4. 책장 소개 밀도, 기억책 제목 반복·스크롤, 보드의 영어 조작명을 정리한다.

## 범위·한계

- 이번 문서는 감사 결과이며 UI 수정·배포 완료 보고가 아니다.
- 40개 예시 카드 일괄 순회 도중 Tabbit 실행기가 120초 제한으로 종료됐다. 현재 화면을 읽기 전용으로 확인해 복구한 뒤 10개씩 나눠 40/40 완료했다(각 묶음 약 60초).
- 캡처 일부는 브라우저의 screenshot timeout으로 재시도했다. 캡처 실패를 제품 작동 실패로 판정하지 않았다.
- 실기기·소프트키보드·스크린리더·새 Google 인증·실제 서버 저장/로그아웃은 이번 검증 범위 밖이다.
- 파일 가져오기·화면 비우기·관련 연결/해제·순간/트리 삭제·mock 로그아웃 UI도 후속 검수 완료. 백업 버튼은 실행했지만 내려받은 JSON 내용 대조는 하지 않았다. 실제 운영 저장/로그아웃 검증과는 별개다.
- 인증/DB/원본 reference/4.0 소스는 변경하지 않았다. 실제 회원 기록은 사용하거나 수정하지 않았다.

복구 후 관리 버튼 9군의 검수도 완료했다. 모든 쓰기는 route.fulfill로 응답한 메모리 fixture에서만 발생했다. 격리 로그아웃 뒤 source/선택이 null인 것을 확인했다. URL은 재사용 컨트롤러의 #start 별칭으로 돌아갔으나 본 검수에서는 선택 정보가 남지 않았다. Google 계정 선택/동의는 조작하지 않았다.

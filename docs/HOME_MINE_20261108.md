# 첫 화면 궤도 — 내 순간 (2026-11-08)

## 바뀐 동작
- 로그인했고 순간이 1개 이상이면 궤도 카드를 내 순간으로 채운다. 순서는 최근 수정(없으면 생성) 순이고, 최대 48장이다.
- 내 순간이 48장보다 적으면 남는 자리만 예시 카드로 채우고 불투명도를 낮춰 흐리게 보여 준다.
- 안내 문구: 내 순간만 있으면 "내가 남긴 순간들이에요", 예시가 섞이면 "흐린 카드는 감상 예시예요". 로그아웃·순간 0개는 기존 문구 그대로다.
- 카드를 누르면 `lt41-select` → `lt41-navigate(track59-sketchbook.html)`로 그 순간이 열린 기억책으로 간다. 흐린 예시 카드는 기존 `lt41-example` 감상으로 남는다.
- 썸네일은 저장된 `mediaMetadata`/`attachment`/`media` 값 중 `data:image`와 같은 출처 경로만 쓴다. 외부 http(s) 이미지는 클릭 전 요청이 생기므로 쓰지 않고 메모 카드로 표시한다. oEmbed를 새로 호출하지 않는다.

## 범위
- `v41/home-moments.js`(신규): 카드 계획을 계산하는 순수 함수.
- `v41/home.js`, `v41/home-actions.js`: 첫 화면 배선과 카드 클릭 동작.
- `src/views/orbit.js`: 예시 채움 옵션과 흐림·클릭 분기만. 궤도 배치·움직임·카메라·금테·정원 테마는 그대로다.
- 셸은 이미 `window.LT41.trees`로 내 트리 목록을 넘기고 있어 추가 변경이 없다.

## 시험
`tests/v41-home-mine.test.mjs`가 로그아웃/0개/3개/가득 참, 최근 수정 순, 썸네일 출처 제한, 기억책 이동 인자, 예시 카드 비선택, 외부 요청 0건을 고정한다.

> 2026-11-08 후속: 예시 흐림은 제거되고 카드 출처 선택(예시/인기/내 것만/섞어서)으로 대체되었다. 최신 규칙은 `docs/PRODUCT.md`의 "첫 화면 카드 출처" 절을 따른다.

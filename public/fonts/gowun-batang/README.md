# Gowun Batang (B 테마 워드마크)

- 파일: `GowunBatang-Bold.latin.woff2` — 라틴 서브셋(Google Fonts 배포 서브셋 그대로, 16KB).
- 쓰는 곳: 첫 화면 테마 B(정원)의 헤더 워드마크 `LoveTree`뿐이다. 한글은 MaruBuri·Pretendard가 맡는다.

- 외부 글꼴 요청은 쓰지 않는다. `public/v41/identity.css`의 `@font-face`가 이 파일만 가리킨다.
